Kebijakan Privasi Kasiva

Berlaku sejak 8 November 2026 · Aplikasi Android com.clonical.kasiva · Pengembang: Kasiva (Muhammad Zaenal Arifin) · Kontak: muzafinarifin.dev@gmail.com

Kasiva adalah aplikasi pencatatan keuangan pribadi. Dokumen ini menjelaskan data apa yang diproses, mengapa, dan pilihan yang tersedia untuk Anda.

1. Mode Lokal (tanpa akun)

Anda dapat memakai Kasiva tanpa akun. Pada mode ini data keuangan hanya disimpan di perangkat Anda dan tidak dikirim ke server Kasiva. Fitur AI dan sinkronisasi cloud tidak tersedia pada mode ini.

2. Data yang diproses saat Anda memakai akun cloud

DataKeterangan
Identitas akunNama dan alamat email dari pendaftaran email/password atau Google Sign-In; ID pengguna Firebase.
Data keuanganProfil, dompet, transaksi, anggaran, target, tagihan, utang, kartu, investasi, catatan, preferensi tampilan. Disimpan di Cloud Firestore milik akun Anda.
Foto profilOpsional, disimpan privat di Cloud Storage hanya untuk akun Anda.

Data AI (opsional)Teks yang Anda ketik untuk AI Chat/Voice, foto struk untuk AI Scan, dan ringkasan angka untuk Asisten. Dikirim ke server Kasiva lalu ke penyedia model AI (DeepSeek) untuk diproses. Foto tidak disimpan oleh server Kasiva setelah diproses; permintaan AI menunggu persetujuan per fitur dan dapat dicabut.
PembelianBila fitur Premium aktif: status pembelian langganan diproses lewat Google Play Billing dan RevenueCat. Pada rilis ini fitur Premium dinonaktifkan.

3. Fitur lokal lainnya

Transkripsi suara dilakukan oleh layanan pengenalan suara di perangkat. Impor notifikasi memproses notifikasi di perangkat dan hanya kandidat yang Anda konfirmasi yang dikirim ke akun Anda. Data impor CSV yang Anda unggah dibaca di perangkat dan hasil yang Anda setujui disimpan ke akun Anda.

4. Tujuan pemrosesan

Mulai versi Android 1.0.3, Kasiva menggunakan Firebase Crashlytics untuk laporan crash, aplikasi tidak merespons (ANR), dan error teknis. Data diagnostik mencakup versi aplikasi dan sistem operasi, model perangkat, ID instalasi Crashlytics, serta lokasi kode yang gagal. Pelaporan ini juga berjalan pada mode lokal; data keuangan lokal tetap berada di perangkat. Log error tambahan yang dibuat Kasiva tidak menyertakan pesan exception asli, email, token login, atau isi transaksi. Laporan digunakan untuk memperbaiki stabilitas aplikasi dan diproses oleh Google Firebase sebagai penyedia layanan.

Menyediakan fungsi aplikasi (mencatat dan menyinkronkan data keuangan, menampilkan statistik, AI opsional), keamanan akun, dukungan pengguna, dan kepatuhan hukum. Kami tidak menjual data pribadi dan tidak menampilkan iklan.

5. Penyimpanan dan penghapusan

Data cloud disimpan selama akun aktif. Anda dapat menghapus akun beserta seluruh data dari dalam aplikasi (Profil → Manajemen Akun → Minta Penghapusan Akun) atau melalui halaman Hapus Akun. Penghapusan akun menghapus data profil, data keuangan, foto, dan data perangkat milik akun tersebut.

6. Keamanan

Data dikirim melalui koneksi terenkripsi (TLS). Akses data dibatasi oleh Firebase Authentication dan security rules sehingga hanya pemilik akun yang dapat membaca datanya. Kunci API penyedia AI hanya berada di server.

7. Anak-anak

Kasiva tidak ditujukan untuk anak di bawah 13 tahun. Kami tidak dengan sengaja mengumpulkan data anak di bawah 13 tahun.

8. Perubahan kebijakan

Perubahan material akan diumumkan di aplikasi atau halaman ini sebelum berlaku. Tanggal berlaku tercantum di bagian atas.
